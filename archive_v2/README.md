# Superseded artefacts

Everything in this directory belongs to the **earlier** study — the EnviroTox-derived,
138-PFAS analysis declined by *Environmental Science & Technology*. It is retained so that
the corrections listed in the top-level README can be checked, and for no other purpose.

**Do not read any number in this directory as a result of the present manuscript.**
In particular `canonical_metrics.json` reports `measured_pfas: 138` and
`envirotox_rows_parsed: 4068`; the present study uses 87 parent structures from ECOTOX.
