# A testing-effort artefact in the most-sensitive aquatic endpoint

Code and canonical results for the manuscript submitted to *Journal of Hazardous Materials*:

> **A testing-effort artefact in the most-sensitive aquatic endpoint: structure-based PFAS
> screening recovers predictive validity but still cannot support clearance**
> Jeongyun Kim, Jin Yoo, Ku Kang

Release `v3.1`. Everything the manuscript reports is regenerated by the scripts in `scripts/`
from the inputs in `canonical_results/`.

---

## What this study claims

Regulatory hazard screening summarises a substance by the **lowest** effect concentration
reported for it. That makes the response variable a function of how much the substance has
been tested. Across 87 PFAS parent structures in the US EPA ECOTOX Knowledgebase the
protective minimum correlates with the logarithm of record count at **ρ = −0.749**
(p = 7 × 10⁻¹⁷). Equalising sampling depth — against the eligible-subset baseline, not the
whole set — removes 40–48% of that, which is an extreme-order-statistic artefact. The
remainder is *not* identified: reverse causation and effort-dependent assay breadth cannot be
separated by this design, and we do not claim otherwise.

Holding a published random-forest model fixed and changing only the external target raises
rank transfer on the same 58 structures by Δρ = +0.32 (95% CI [+0.08, +0.57], p = 0.005).
Rebuilding on an effort-stable acute median restores external validity (R² = +0.367,
ρ = +0.460 [+0.22, +0.65]). Clearance of untested PFAS nevertheless fails at every threshold
matched to the protective endpoint for stringency.

## What this study does **not** claim

- It does not claim that representation choice is irrelevant. It is not:
  `canonical_results/endpoint_representation_results.csv` shows that swapping ECFP4 for 165
  RDKit descriptors moves rank transfer on the protective minimum from ρ = −0.03 to +0.42.
  An earlier version of this work asserted the opposite and that assertion is withdrawn.
- It does not identify the residual association as reverse causation.
- It does not propose substituting a median into an existing assessment-factor schedule.
  Those schedules are calibrated over a lowest value; no calibration exists for a median.
- It does not claim the acute median is a species-level quantity. The ECOTOX extraction
  re-used here carries no species field, so it is a median over **records**. A
  species-aggregated endpoint feeding an SSD is the right next step and is not done here.
- It does not present the 33.9% / 1.9% clearance fractions as deployment-ready numbers; they
  depend on an applicability-domain rule that is permissive (see `archive_v2/` note below and
  SI §S10).

## Layout

```
scripts/              analysis, start to finish
canonical_results/    inputs and outputs of THIS study
archive_v2/           superseded artefacts of the earlier (ES&T-era) study — do not mix

```

### Order of execution

| step | script | produces |
|---|---|---|
| 1 | `extract.py` | freshwater records from the ECOTOX ASCII release |
| 2 | `resolve_smiles.py` | CAS → SMILES via PubChem |
| 3 | `recurate.py` | **parent-collapsed, de-duplicated** per-substance table + effort statistics |
| 4 | `subsample.py` | equal-depth subsampling against the eligible-subset baseline |
| 5 | `endpoint_fix2.py` | fixed-model endpoint swap, matched sample, bias-corrected R² |
| 6 | `oecd_classify.py` / `run_oecd.py` | OECD (2021) gate and structure categories |
| 7 | `forest2.py` | class-resolved transfer on the acute median |
| 8 | `final_pipeline.py` | consistent rebuild, conformal intervals, inventory clearance |
| 9 | `make_fig01.py`, `make_fig02.py`, `make_fig03.py` | Figures 1–3 |

Every figure script ends in a layout assertion: measured text extents are checked for
overlap and for falling off the canvas, and `make_fig03.py` additionally asserts that each
tick label sits on the row of the class it names.

## Corrections made in v3.1

These are listed because each was wrong in `v3.0` and a reader comparing releases should
know which numbers moved.

1. **Structure standardisation now precedes endpoint summarisation.** In `v3.0` the
   per-substance table was built from 103 CAS registrations and the desalting rule applied
   only downstream, so ten registrations resolving to perfluorooctanesulfonate entered the
   analysis separately at ten different testing depths. Collapsing them gives 87 parents.
   Effect: ρ moves from −0.734 to **−0.749**.
2. **Exact duplicate rows removed before counting effort.** 15,991 rows contain 4,744
   distinct (test, endpoint, concentration, unit) tuples from 2,182 tests. Counting effort on
   distinct tests instead gives ρ = −0.703.
3. **Subsampling compared against the eligible-subset baseline.** The `v3.0` figure compared
   depth-equalised correlations with the whole 103-substance value, which mixes a change of
   sample with the effect of depth. Corrected, the depth effect is 0.30–0.36 and stable in
   *k*; the apparent k = 20 anomaly disappears.
4. **Subclass analysis recomputed on this study's data.** `v3.0`'s `make_forest.py` read a
   hardcoded local path to the ES&T-era 119-structure file, which is not in the repository;
   Figure 3 was therefore not reproducible and was not from the 103-substance extraction. The
   previously reported ρ = +0.695 for perfluoroalkyl ether acids **does not survive**
   recomputation. No class now excludes zero.
5. **Four defects in the OECD classifier fixed** (unsaturated perfluoroalkenoic acids falling
   to a residual category, acids not distinguished from ketones and esters, class 700
   assigned to any molecule with a ring, and a fluorotelomer floor low enough to admit
   fulvestrant). See SI §S8.
6. **Per-repeat conformal results deposited** (`rebuild_v2_conformal_repeats.csv`) instead of
   means only, so the reported coverages and widths carry a spread.
7. **Stale result files quarantined** in `archive_v2/`. In `v3.0` several files carrying
   EnviroTox-era numbers sat alongside the new ones with no marking, while the Data
   Availability statement claimed the repository regenerates every reported number.
